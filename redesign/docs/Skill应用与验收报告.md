# Alethic 官网重写 · Skill 应用报告

## 设计对象

访客可以停留在全屏字符开场，也可以点击、滚动或按 Enter 进入长首页。正文保留研究方向、项目、成果、团队、资料、会议和加入路径。官网接口延续公开路径并使用原组织的业务服务。会议页演示从征稿到公布的流程。

开场使用 12 列桌面坐标和 4 列手机坐标。字号、字符间距与列宽适配实际视口。滚动把字符收向一条基线，基线伸展成刻度和定位线。正文沿用列宽安排导航、主标题及内页分区。当前章节、选中阶段和实验结果保有各自的可读标签。视觉层级由冷白或墨蓝底、正文墨色、次要文字、弱分隔线及蓝靛定位组成。

## 使用了哪些 Skill

| Skill | 采用的原则 | 在新版里的体现 | 复核方式 |
| --- | --- | --- | --- |
| **Oil UI** | 先确定主视觉、主要任务和留白，再验静帧与任务路径。用线时明确它划分什么或指向什么 | 首页开场的唯一可见主题是团队字标及短语。正文导航是一条可以操作的索引带。研究方向、成员、会议各用对应内容组织版面 | 对照 1440 与 390 的开场、正文与内页截图。走一遍首页到研究演示，并单独检查键盘路径。 |
| **Motion Web** | 先做静态可读的终帧。以真实内容安排动效节奏，并选足够的技术层级 | 首屏将品牌字形采样到 ASCII 网格。在停留时局部换字，并按顺序切换三组字形。滚动改变同一批字符的位置和密度，描绘工程线。页面由静态 HTML、CSS 与 Canvas 实现 | 对比开场的连续帧及滚动中间态。关动效以后复走入口、深链和页面操作。 |
| **Refactoring UI** | 用字号、留白和对比排序，减少同强度分隔。先定令牌再做组件 | 正文按主标题、索引、正文、注释排序。共享 `--paper`、`--ink`、`--muted`、`--line`、`--accent`，深浅主题替换语义值。内容区用纸面与通长行线排列 | 检查长页是否有清楚的阅读层级，同一控件在中英、深浅与窄屏是否仍能区分焦点和选中。 |
| **Emil Design Engineering** | 高频反馈短、可中断，状态更新有明确因果 | 导航定位符的移动为 160 ms。焦点和选中项立即出现。开场指针反馈在原字符坐标上局部提亮，离开后回落。会议切换使用当前输入直接更新阶段和说明 | 连续操作不同阶段，检查选中项、图和说明是否一致。移入移出开场，观察反馈是否随当前位置变化。 |
| **Impeccable** | 记录面向谁和设计约束，按响应式、状态和实现一致性自查 | `PRODUCT.md` 固定读者任务、跨端列数和视觉边界。共用语义链接与控件，包含系统减少动效、出错状态和真实业务入口 | 检查三种宽度、主题和语言跨页、404、预录数据标记、加载失败等实际状态。 |

## 案例如何迁移

- **BUCK × Coinbase** 的字符编排启发了字形变成另一种结构。Alethic 用同一组字符坐标表达名称、短语、再到刻度轴。[案例原文](https://www.stashmedia.tv/buck-cracks-the-code-for-coinbase/)
- **Herbarium** 的标注和解释对应到具体对象。Alethic 在研究页把切分位置、当前模型和结果保留在同一读出区。[案例原文](https://ui.oiloil.org/works/herbarium/)
- **Relay** 让一个操作同时影响路径、标签和结果。Alethic 的会议阶段、图例及说明都从当前选择得出，对应的研究图按真实筛选条件更新。[案例原文](https://ui.oiloil.org/works/relay/)
- **Agent HUD** 的场景连续性启发了开场与正文的交接。开场坐标收束至基线，正文按这个坐标重新组织路径和信息。侧边讨论

参考视频的 2、3–6、10、18 秒片段分别提供了字形层级、尺寸标注、稳定标题和状态叙事的依据。镜头不能证明鼠标因果关系。新版在网页中独立验证指针响应、滚动行程和点击后的焦点位置。

## 复用时的检查

桌面内容纸面宽度为视口的 91%，最大 1520 px。窄屏 760 px 以下用 4 列。正文网格可以拆成不同跨列关系，章节节奏通过 64–128 px 的段间距控制。先排完真实标题和数据，再使用等宽字符形成结构，最后让定位线与当前内容一起更新。需要辅助图形时，先定义图形的输入、选中项和可读替代信息。

页面入口使用可聚焦的真实链接，局部状态使用按钮、输入或选择控件。焦点与选中有不同的描边、下线或底色。现场状态以文字为准，减少动效时保留全部信息与操作。只有当前在视口内且标签页可见时才推进开场时钟。

B 端映射从语义色、字号和状态反馈入手，再用 Ant Design 的表格、表单和阶段组件表达工作流。官网的开场与纸面构图服务于公开阅读。评审平台的行选择、录入与确认服务于长期操作。

## 独立视觉评审后的修改

初轮评审给出 **7/10**，指出正文首次呈现缺少能辨认出这家实验室的研究内容，阶段选中标记与研究章节不一致，手机端尾格没有闭合，FLUED 的首个研究内容进入视口太晚。

- 首页右栏由实际 FLUED 预计算结果生成。S0 与 R4 两条线上的 `|` 用真实字节偏移生成，用户可进入总览查看原样本和每段内容。中文样本为 503 B，对应 13 段与 24 段。英文界面使用英文样本的对应数值。
- 会议和研究章节统一使用括号标识当前项与下沿定位线。会议保留选中阶段对应的路径和记录。
- 移动端导航末项覆盖该行剩余两列。为窄屏重画 ALETHIC INSIGHT 的 ASCII 字形。FLUED 缩短标题与第一段之间的距离。

## 全站字符动效修订 · 2026 年 11 月 22 日

对照用户提供的 1852 px 截图，旧导航的成员与会议栏各占一个网格单位，其他栏目占两个。旧页头还将账号、显示偏好和动效开关排在同一行。新版将八个栏目铺在等宽、等高的格子内，手机分为两行。GitHub 和 Hugging Face 组成资源入口组，登录与个人中心组成账号组，语言和主题组成显示设置组。页眉和浏览器图标使用原站 `mark.svg`。动效服从系统减少动态效果设置。

此次采用了三个项目的交互方法，前端实现由工程内的原生 JavaScript 和 CSS 提供。Motion Web 用于把开场循环、滚动及页间交接安排成连续动作。Choreograph 用于确定动作先后顺序，先标示当前操作，再让目标页面接续。Animation Performance 用于控制可见画布的更新频率、停用后台绘制、按尺寸缓存字形。Oil UI、Refactoring UI 和 Impeccable 用于核对真实截图中的导航比例、窄屏排列和层级。Emil 的短反馈原则用于鼠标、触屏及键盘激活。

正文里的字符有三种具体用途。栏目边界上的短标尺持续定位当前章节，页边导线追踪阅读位置并响应控件，标题区的字符图按页型改变。研究页的分段和曲线仍显示实际数据，会议切换同步显示阶段路径与文字记录。焦点、操作按钮和实验结果始终可读。

## 长首页正文交付

## 首页图案、正文层级与导航修订

本轮为首页 11 个正文段落各绘制了一幅动态字符图。组织结构用三层叠片，研究方向用波形带，获奖成果用三枚刻纹，文档用纸张截面。图形随停留和指针运动改变局部密度，屏幕阅读器略过这些装饰。FLUED 的真实字节刻度与可操作模型选择器继续承担读数任务。社团席位、工作约定和加入步骤用普通文字呈现。

开场在整句可读期间持续更新两种区域。字形内的明暗波交替使用加号和井号，字形外的稀疏字符在另一节奏下更新。切换站点主题时同时重画墨色与背景。系统减少动态效果时，各幅字符画显示完整静帧。

## 整块阅读遮罩与控件复测

用户截图中的 FLUED 标尺和文章目录都包含重要的空白。过去的净区按文字与控件的具体位置计算，滚动或展开后，背景图会进入这些空白，导致实际阅读受干扰。本次以原有阅读区域的完整矩形参与绘制布局。边界之外的留白可容纳主题图时，图形移动至该处。移动端阅读列占据视口时，画面优先显示内容。

Oil UI 的实拍检查采用截图中的两种内容状态。Motion Web 与 Emil 的反馈规则用于核对目录跳转的启动、途中接管和到达焦点。Refactoring UI 用于统一资源链接、主操作、列表选择、表单输入和折叠入口的层级。以 Impeccable 的键盘、窄屏和减少动态效果检查复核桌面与手机。原生平滑滚动项目的时长与导航偏移设置为本次自定义滚动提供了参考。 [Smooth Scroll 源项目](https://github.com/cferdinandi/smooth-scroll)

站内长页锚点按实际距离设置 320 至 880 毫秒的滚动时长，并计入吸顶栏高度。可用滚轮、触屏、方向键或 Esc 中断，系统开启减少动态效果时直接定位。到达后焦点落在目标章节。桌面在页边通过 `[Aa]` 打开语言和外观偏好，手机采用页眉下的文档流布局，为阅读和触控留出空间。
