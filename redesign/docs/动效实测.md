## 复跑

在项目根目录，保持预览服务在 14118。用 PowerShell 运行，两条脚本均在断言失败时返回非零退出码。

```powershell
$env:ALETHIC_QA_RECORD = '1'
$env:ALETHIC_QA_OUTPUT = Join-Path $PWD 'qa-output/runtime/recheck'
node scripts/browser-qa.mjs
node scripts/motion-qa.mjs
```

本次用项目已有的 Puppeteer 驱动本机 Edge，浏览器内置控制插件在此会话不可用。FFmpeg 负责将 Chromium 实录转为可播放的 H.264 MP4。测试使用浏览器触屏仿真和系统媒体设置仿真。
