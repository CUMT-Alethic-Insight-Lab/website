# Alethic Insight 品牌视觉规范

## 色彩和字族

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 `--paper` | `#f3f4f8` | `#14182d` |
| 交互底色 `--surface` | `#e8ebf4` | `#1d2440` |
| 正文 `--ink` | `#171c34` | `#eff1fc` |
| 次要文字 `--muted` | `#505c78` | `#b4bdd5` |
| 链接、选中、焦点 `--accent` | `#333fa3` | `#adb7ff` |
| 普通分隔 `--line` | `#a0a9c1` | `#535e80` |
| 关键控件边界 `--strong-line` | `#687590` | `#8592b9` |

系统无衬线负责标题、长文、表单标签和阅读结果。等宽字族负责字符画、坐标、参数、章节索引和步骤编号。长文正文 16 px 起，行高约 1.65，阅读宽度最多 72 ch。用 8 px 基础间距划分组内节奏，段间距由 64 到 128 px 随视口变化。

## 把字符和线条用作结构

1. 确定此页唯一的核心任务，以及能代表这项任务的对象。首页用品牌字样和一个实际研究实例。FLUED 用字节边界、模型和读数。会议用稿件各阶段。成员页用同一基线对齐成员名称、职责和公开产出。
2. 以共享纸面宽度排信息。宽度为视口的 91%，上限 1520 px。桌面 12 列，低于 760 px 用 4 列。开场字符场的列数取逻辑列数的倍数，让字符坐标可对齐正文的边界。内容区按阅读任务跨列，窄屏时展开为单列阅读。
3. 线条分工固定。横线是栏目基线或数据刻度，竖线连接共享基准或分开数据与说明。`+` 标出定位原点，`[ ]` 表示当前章节或选区边界，`|` 映射到读数或资料中的实际切点，`->` 通向具体操作结果。字符标注与语义 HTML 共存，辅助字符由辅助技术略过，相应链接、名称、选中状态及数值有可读文本。
4. 选中高亮同步到结果。导航到一个章节时定位符和实际章节顶线对应。切换稿件阶段时当前项、阶段图与记录同时更新。Focus 线条保留独立的 2 px 外轮廓，选中以底边定位线、色差和语义状态共同表达。

## 动效与输入

| 动作 | 默认反馈 | 静帧行为 |
| --- | --- | --- |
| 停留在开场 | 每组字形停留约 3.8 秒，粒子沿弧线飞行约 1.6 秒，组成下一组字形。鼠标能推开字符，移开后它们逐渐归位。后台、离屏和系统减少动态效果时停止循环 | 保留完整字标及可激活区域 |
| 点击或向下滚动 | 字符收向基线，定位角和刻度随卷页动作出现。点击进入正文，对正文入口移动焦点 | 直接到达相同正文，可继续阅读和操作 |
| 导航悬停与按下 | 约 160 ms 的定位符短移，激活时即时给出选中或按下信号 | 继续显示可见焦点和选中态 |
| 站内页面切换及返回 | 出发位置发出字符扫描线，下一页在相应高度接续。浏览器历史负责页面、锚点和阅读位置 | 直接显示目标内容与焦点 |
| 阶段切换 | 立即替换选中项和可读记录，定位线用 240 ms 显示连接方向 | 图、记录和当前项即时就位 |

触屏用点按，保留按下状态与选区。图形尺寸依据触屏可读性和字形完整性取值。短时动画避免拖慢频繁操作。选择、返回、加载失败及空结果以界面文案表达。

## 给其他实现者

从这个站点新增研究子页时，先画本页唯一的读数关系，再确定页面中哪些标签、选项和说明直接对应坐标。实际提交一个状态联动，例如从数据集筛选到图表读数和样本说明。1440 px 看栏目和留白，390、320 px 看能否找到入口、读到内容和准确点按。最后复测键盘、减少动效、旧链接和异常响应。

B 端独立使用自身的表单、表格和流程结构。将本规范中的语义色、焦点、识别符与阶段反馈映射到 Ant Design。办公场景的密度由任务决定。两个工作场景的实际复用结果、主题令牌表和未接入项见对应文档。 [B 端品牌复用](../docs/B端品牌复用.md)

## 长首页字格规范 · 2026 年 11 月 22 日

首页采用固定的等宽字符地址。每格按空白、点、冒号、加号、井号逐级擦写。完整品牌字样停留约 3.8 秒，邻行陆续改写后形成下一组。悬停或触摸改变附近格位的密度。入场时同一片轮廓沿列改写为导航基线，四组刻度在相同宽度上生成，最后显出栏目标签。

正文用关系选择图形。工序沿线排列，层级从公共分支展开，选择器把索引接到具体释义，证书与人员信息对齐，文档按目标来源分组。公共章间线只负责引导视线。新章节先用一组真实内容验证关系，再用键盘、触屏、减少动效状态和隐藏公共线后的静帧确认阅读顺序。适用于本次重写的实际版式与例图见[长首页逐章验收](长首页逐章验收.md)。

## 动态图案和正文阅读层级

首页章节标题配独立的等宽字符纹样，依据画面宽度安排在标题旁或侧栏。亮色使用浅纸底和蓝靛墨色，暗色使用深靛底和亮色墨迹。纹样配合内容选择造型，例如组织层级的叠片、获奖成果的印记、文档的书页；实际信息通过标题、数字、控件和清楚的链接传达。主页位于主视口时，开场字形与背景都持续更新，背景对比度低于字标。可复用的效果与验证见[Skill 应用报告](Skill应用与验收报告.md)。
