# 实验室首页与技术文档改版记录

访客进入第一幕时，左侧先读实验室主张，右侧了解团队归属。下方一幅固定字格的字符图依据采样、建模、验证和交付四项操作改写形态。四项操作共用一个说明区，选择后同步更新；系统开启减少动态效果时显示完整静帧。

获奖区提供三支队伍的索引、一组随选择点亮的字符奖章和对应的原始证书。桌面指针移入队名或键盘焦点抵达时即可预览。触屏以点按选择。图、队员名单、指导教师、证书编号和 PDF 共用同一条记录。

组织图从实际文字和控件位置测量端点。开放参与连到社区，同步直招并行连到社团和实验室。参与说明、原计划席位、成员名录与招新入口在同一阅读区域。技术文章使用阅读区以外的字符装饰，点击目录沿页面滚动至对应标题。

## 自查与修正

- 往返滚动时，旧版会反复按当前可见留白寻找最大的矩形，导致图形重新定位。此次采用相对章节的绘图位置，视口滚动投影到同一网格。正向与反向滚动分别检查。开场中的定位线与第一幕使用同一参照位置。
- 项目页将项目名、切分对照标题和方法选择分开排列，选择器焦点框与刻度线之间留出空间。分段数和最右边界仍按原始样本绘制。
- 手动复测发现，手机从第三队的深链进入时，第一队按钮会被吸顶栏挡住。窄屏将三个队名放在同一行。桌面深链给上方队名保留空间。
- 技术文章的目录、菜单和链接通过浏览器的焦点、位置与中间帧进行核对。吸顶栏只为被遮住的键盘操作补足滚动距离。桌面导航提供悬停打开和退出反馈，触屏仍用点按。

Oil UI 用于核对桌面与手机实拍。Motion Web 和 Choreograph 用于核对入场、滚动及抽屉开合的中间态。Refactoring UI 用于调整标题、图例、正文与证书信息的主次。Emil 的反馈原则用于处理快速切换、悬停和焦点。交互排查参考 Scrollama、The Pudding 的阅读步进机制，以及原站 `src/bg/cursor.js` 的指针行为。 [Scrollama](https://github.com/russellsamora/scrollama) · [The Pudding](https://github.com/the-pudding/website)
