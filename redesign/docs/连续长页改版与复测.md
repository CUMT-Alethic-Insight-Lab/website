# Alethic 连续长页改版与复测

## 浏览方式与信息层级

开场、实验室介绍、组织结构、研究方向、三大面向、公开项目、获奖成果、协作公约、关键文档、会议与评审、加入方式共用同一份首页文档。正常滚动经过视口内的阅读位置时更新当前章节、顶栏和画布。1440 × 900 桌面下，每幕按扣除页眉后的可用高度编排。手机使用自然高度，内容较多时允许顺着当前幕读下去。资源目录可在公开项目幕内展开。

此前把「一页」当作一个网址，又把每个选项的响应局限在同一幅图的高亮变化。此次将视口作为排版单位，将读者当下的选择作为图形内容的输入。专题与内容较长的研究详情仍可从相关入口进入。原先分开的主题网址可找回对应章节，研究方向的旧深链可直接选中原条目。

## 研究选择与阅读净区

| 方向 | 点击后出现的形态 |
| --- | --- |
| NLP / LLM | 词序列切分为不同长度的分段 |
| CV | 像素图像与取景框 |
| VLM / MLLM | 图像与文本两路输入汇合 |
| RL | 动作与奖励的反馈环路 |
| Agent | 规划路径和行动节点 |
| Memory | 分层存储与检索路径 |
| AI Infra | 机架与连接总线 |

字段和操作采用正常的网页文字。绘制字符前先取得当前文字、列表与控件的阅读区域，在这些区域清空背景墨迹。绘制由视口章节和选中方向共同驱动。反向滚动时，同一字格接续改写上一节的形态。系统减少动态效果时直接呈现目标静帧。

## 参考与设计审查

参考 Scrollama 的滚动叙事步进机制和 The Pudding 网站的 Scrolly 示例，把章节触发与实际滚动位置对应。工程沿用浏览器原生滚动与现有 Canvas。[Scrollama](https://github.com/russellsamora/scrollama) · [The Pudding](https://github.com/the-pudding/website)

Motion Web 和 Choreograph 用于安排同一字格的进出节奏。Emil 的反馈原则落实为可打断的选中反馈与键盘焦点。Oil UI 与 Refactoring UI 用于核对每幕在静帧下的主次、留白和控制位置。Impeccable 的窄屏检查覆盖语言、主题、长标签和菜单。图标有可访问名称，Hugging Face 与 GitHub 保留可见文字，便于首次访客辨认。
