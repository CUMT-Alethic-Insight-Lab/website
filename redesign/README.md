# Alethic Insight 官网重写

这个目录可以独立构建中英文公开页面。运行以下命令可启动本地预览。

```powershell
npm run build
npm run preview
```

打开 `http://127.0.0.1:14118/`。首屏可以停留，看三个品牌字样循环，也可以点击或向下滚动。直接访问 `/#work` 可以定位研究目录。

- [Skill 应用与验收报告](docs/Skill应用与验收报告.md)
- [部署与业务验收](docs/部署与业务验收.md)
- [品牌视觉规范](docs/品牌视觉规范.md)
- [B 端品牌复用](docs/B端品牌复用.md)

公开页面在 `dist/`。本地静态预览的登录、账号和招新入口显示服务未连接。预发接入既有同源服务后的核验步骤见部署文档。会议页面提供四阶段流程演示。
