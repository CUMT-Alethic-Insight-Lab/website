# 序章叙事与粒子特效设计：从「开场表演」到「全文索引」

- 日期：2026-10-02（2026-10-03 修订：补入 careers.kimi.com 运动语法实测，见 3.4）
- 范围：`website-spa-proto`（vite + 原生 JS + Canvas 2D）首页序章与粒子系统
- 状态：设计稿，待用户评审；本文不含实现代码
- 路径分类：architectural（改动重组粒子系统与首页叙事结构的关系，接口影响 shell.js / scene.js / index.html / styles.css）

## 1. 背景与问题

现状（已验证的原型行为）：

- 首页首屏是 100svh 虚空序章，约 1400 颗粒子循环三幕：品牌 mark（A 字 + 蓝色方块）→ 真知灼见 → 由繁得构 · 由构显真。
- 粒子尺寸 1.8–2.6px，`fillRect` 方块渲染，单色纪律：主体 `--ink`，蓝色方块与最大颗粒用 `--accent`。
- 滚过序章后场景随滚动淡出归零；子页（people / insights）无粒子场景；FLUED 五页与招新平台整页跳转、不参与。
- 序章之下是静态排版的正文（hero、定位、七个方向、三大面向、项目表、成果表、协作公约、文档、加入），与序章在叙事上完全割裂。

用户提出的三个新方向：

1. 粒子可以更大（现状 1.8–2.6px 太细）。
2. 效果可以更炫酷。
3. 内容展示可以更一体化——粒子系统不应只是序章里孤立的三句循环。

核心设计问题：粒子系统如何从「序章里孤立的三句循环」进化为「承载整站叙事的媒介」，同时守住全部硬约束。

## 2. 硬约束（复述，全文遵守）

1. 粒子绝不做全屏墙纸、绝不压在正文后面；正文区域永远干净。负空间是构图的一部分。
2. 粒子必须承载身份/信息，炫酷必须服务于叙事。
3. 只用简体中文，严禁繁体（队形文字、章名、注释均遵守）。
4. 配色取自站点 CSS 变量（`--ink` / `--accent` / `--paper` / `--muted` 等），与整站视觉一致。
5. FLUED 五页与招新平台不参与特效。
6. `prefers-reduced-motion` 降级链路必须保留。
7. 站点功能（logo 回首页、语言/主题切换、导航、章节轨）不能因特效受损。

## 3. 三个方案与取舍

### 方案 A：全站滚动劫持章节制（careers.kimi.com 完整形态）

把首页改造成滚轮劫持的章节序列：滚动被锁定，每次滚轮输入推进一章；每章一个粒子时刻（成形 → 退场），随后正文以全屏章节形式显现。粒子场景贯穿首屏到页尾，共 6–7 章。

- 优点：叙事张力最强，与 careers.kimi.com 参考形态一致；「一体化」做到极致。
- 缺点：
  - 滚动劫持剥夺用户滚动主权，与章节轨（section-rail）锚点直达、浏览器查找页内文本、触控板惯性滚动全部冲突；
  - 首页正文需要重组为全屏章节，排版与信息密度大改，超出「特效设计」范围；
  - careers.kimi.com 是招聘品牌营销页，本站点是研究共同体的工具型官网，信息效率优先于仪式感的场景更多。
- 结论：不推荐作为主线。其「每章一个粒子时刻」的思想被方案 C 吸收。
- 实测补充（2026-10-03，详见 3.4）：kimi 全站仅 7 章、每章信息极简（一两行字），且自带「校园招聘/社会招聘」直跳按钮为不想看叙事的人留旁路——劫持在它那种营销页成立，本站首页的信息量与工具属性不具备这个前提。

### 方案 B：序章强化 + 归位（保守演进）

保持现有信息架构完全不动，只升级序章：更大粒子、更强物理（弹簧/涡旋/指针交互）、三幕节奏收紧；序章最后一次成形后，队形缩小飞入页眉 logo 完成「归位」，随后正文照旧静态排版。

- 优点：风险最小，所有约束天然满足；改动集中在 scene.js。
- 缺点：只回应了方向 1 和 2，方向 3（内容一体化）基本没有回答——正文与粒子仍是互不相干的两幕。
- 结论：作为方案 C 的前两期交付物被包含，不单独作为最终方案。

### 方案 C：粒子间奏带穿插正文（推荐）

不劫持滚动。在首页正文区块之间插入 3 条「粒子间奏带」+ 1 条终章带：每条带是一段约 120–150svh 的纯负空间区间，粒子在其中组成**该区间之后正文区块的真实内容关键词**（七个方向缩写、FLUED、一等奖），由滚动进度驱动成形与散开；带滚过后粒子完全消失，正文在干净的版面上呈现。终章带中 mark 队形缩小飞入页眉 logo，完成「背景 → 界面元素」的归位闭环。

- 优点：
  - 方向 3 得到正面回答：粒子承载的是真实内容（方向词、项目名、奖项名），成为「全文的视觉索引」——用户在正文中读到的一切，都先在粒子里见过一次；
  - 约束 1 结构性满足：间奏带物理上就是负空间，正文区永远无粒子；
  - 无滚动劫持，滚动主权、章节轨、锚点、查找全部保留；
  - 对现有架构是增量扩展：scene.js 加一种滚动驱动模式，shell.js 加带注册与进度计算。
- 缺点：首页总长增加约 490svh，需控制带高与节奏防止滚动疲劳；滚动驱动状态机是新的心智负担。
- 结论：推荐。

**一句话叙事弧**：粒子在序章凝成品牌，随后三次在正文之间以内容关键词显形（方向星座 → FLUED → 一等奖），终章归位于页眉 logo——粒子从「开场表演」变成「全文索引」。

以下章节全部按方案 C 展开。

**提炼出的动效词汇表**：

1. **镜头推移（viewpoint morph）**：ch1→ch2 全程约 0.8–1.2s（视频 `kimi-ch1to2.mp4`）：同一粒子主体做队形级变换（放大 + 平移），绝不散开重组——主体连续性优先于形态炫技。
2. **字符雨溶解（char-rain dissolve）**：站点签名转场：随机 ASCII 字符自顶部灌入覆盖旧场景约 0.5s，旧场景溶解、新场景随即成形；切换全程约 1s。证据 `kimi-ch3-f02.png`、`kimi-ch5-f02.png`、`kimi-ch7-f02.png`，视频 `kimi-ch2to3.mp4`。
3. **退出-入场（exit/enter）**：新主体可以从画外滑入（胶片条），不必与旧主体形态继承。
4. **一种材质贯穿全站**：同一抖动月面在所有尺度复用（小月球 → 巨月 → 小月球群 → 全屏月面），整个叙事弧就是「飞向月球并登陆」；色彩严格单色（白/灰 on 黑），全站无强调色。
5. **idle 即叙事**：公转、胶片滚动、星点闪烁、月面漂移——没有静止的成形画面，每章都有自己的时间维度。
6. **章内信息极简**：每章正文仅一两行字或一排数字；粒子主体承担「章题」，文字退到内容层。第 5 章证明：纯排版章与粒子章可以交替，不必每章都有粒子。

**与本设计约束的冲突记录**：kimi 在第 3/4/7 章实际使用了全屏抖动纹理（隧道墙、字符底纹、全屏月面），即本设计约束 1 禁止的「全屏墙纸」；其字符雨转场是瞬间全屏噪声，性质接近但寿命仅约 0.5s。本设计只借运动语法，不借全屏纹理，约束 1 维持更严。

**实测对方案结论的影响**：方案 C 结论不变，且被强化——kimi 的「每章一个粒子时刻」与间奏带同构；其切换时序（约 1s）与本设计章 0 节奏（700/1800ms）及 scrub 曲线比例一致；其 idle 设计佐证 hold 段呼吸与锚点轮询的必要性。两项具体修订见 5.3（退场词汇）与 5.4（dock 手法实测验证）。

**交互词汇表（可借 / 重复 / 互补）**：

1. **反色（invert）hover —— 可借**：kimi 全站可点元素的统一反馈语言（导航 200ms、按钮精灵图 100–150ms、CTA scale-110 200ms），严格单色下最响亮的 hover 信号。本站现状 cursor.js 有指针反馈但按钮本体无反馈，可在 styles.css 为按钮/链接补一条 invert hover 规则（成本一行，词汇与全站单色纪律兼容）。
2. **悬停显影 —— 可借（核心佐证）**：胶片显影 = 「噪声→成形」应用在指针态，与本设计「由繁得构」同源，等于 kimi 替我们实测验证了 hover 版噪声收束的观感（500–750ms 收束 + 移开复原）。候选落点（P5，不进 P1–P4）：章 1 七词星座 scrub 静止时，指针扫过某词可局部收束提亮。
3. **悬停冻结复杂系统 + 信息卡 —— 可借（礼仪性）**：公转冻结降低阅读成本，是持续运动系统的通用 hover 礼仪。本设计间奏带 scrub 静止时本无大动画，不需要；章 0 hold 段的锚点轮询点亮可考虑 hover 暂停轮询（P5）。
4. **双态指针语义 —— 互补**：kimi 用 CSS 位图替换（default/pointer 两态），实现简但形态天花板低（无填充、无磁吸）。维持 cursor.js 的 canvas 绘制路线，其 hover 态缩放已覆盖同等语义，不降级。
5. **粒子斥力参数结论 —— 维持 140px / 40px**：kimi 全站粒子场对指针完全免疫（无斥力、无引力、无尾迹），证明「粒子不响应指针」是成立的干净路线，但也意味着我们的斥力无实测对照参数可校准；其 hover 微交互全部走「二元开关 + 200–500ms 补间」而非连续力场，与我们斥力（服务噪声态玩味的连续力场）定位不同，不构成反证。若 P5 做漩涡尾迹，建议尾迹衰减时间参考胶片显影的 500–750ms 区间。引力维持不做（5.1 已决，kimi 亦无引力实例）。

**对既有规格的修订**：无推翻项；两处结论获新实测佐证——① 5.1 指针交互参数维持不变（依据见上）；② 第 10 章「Scramble 仅作正文标题微交互候选」获佐证：kimi ch1 进场标题即 scramble 乱序揭示（证据 `kimi-hov-ch1-base.png`），限于标题级元素使用，与粒子成形语义不冲突，维持「不在本设计范围」。

- **章 4 不碰真实 logo**：粒子在到达前 12% 行程内淡出至透明，视觉上是「飞入并融入」，页眉 logo 元素全程不被特效读写（约束 7）。回顶（点 logo / 点章节轨 Top）后场景重置回章 0。

## 5. 特效规格

### 5.1 粒子系统总规格（全章共用）

**尺寸分级**（回应「粒子更大」）：

| 档位 | 占比 | 成形时尺寸（桌面） | 颜色 | 作用 |
|---|---|---|---|---|
| 锚点 anchor | ≤2% | 6–8px | `--accent` | 队形特征点（笔划交点、mark 方块角、词首），视觉焦点 |
| 核心 core | ≈70% | 3–4.5px | `--ink` | 队形主体 |
| 尘埃 dust | ≈28% | 1.5–2px | `--ink`，低透明度 | 填充间隙、噪声态主体 |

移动端整体降 30%（锚点 4–5.5px）。噪声态（k=0）下所有粒子尺寸收缩至 60%、透明度 0.05（现有 DUST_ALPHA 语义保留）。

**数量**：桌面 2400（现状 1400），移动端 900（现状 620）。提升数量 + 增大尺寸后，文字队形从「稀疏点阵」变为「致密织物」，这是「更炫酷」的主要来源，而非堆砌颜色或全屏噪声。

**渲染**（scene.js 渲染路径升级）：

- `fillRect` 方块 → 预渲染圆形径向渐变 sprite，`drawImage` 贴图。圆形避免大粒子方块与像素墙过场（transition.js）产生视觉混淆。
- sprite 预渲染 6 张：3 档尺寸 × 2 色（ink / accent），启动与主题切换时重建（复用现有 MutationObserver 刷新机制）。
- 不启用 `shadowBlur`（每帧全粒子模糊超出预算）；发光感由 sprite 径向渐变自带的外晕承担。

**物理**（scene.js 运动模型升级）：

- 粒子增加速度场 `vx, vy`。
- gather：弹簧模型 `v += (target − pos) × 0.09; v *= 0.86; pos += v`，产生轻微 overshoot 回弹（现状是线性 lerp 系数 0.16，无回弹）。
- scatter：径向外推 + 切向分量（涡旋），切向速度 0.6–1.2px/帧，方向按粒子索引奇偶交替，形成旋转散开。实测依据：kimi 第 3 章的粒子隧道即涡旋的终极形态（3.4 章节表），本设计取其在「散开」阶段的弱化版本。
- hold：队形整体呼吸缩放 ±1.5%（0.8Hz 正弦），叠加现有 per-particle wob。
- scrub 模式：k（聚合度）直接由滚动进度计算（见 5.3），滚动停止时粒子停在对应 k，但呼吸与 wob 继续——scrub 场景也要有生命感。

**指针交互**：

- 斥力半径 90→140px，斥力强度 26→40px（现有机制参数加强）。
- 可选增强（P5）：指针移动速度超过阈值时，路径上的粒子获得短暂切向扰动（漩涡尾迹）。
- 不做「按住吸引」：按住填充已是自定义指针（cursor.js）的语义，粒子侧再加引力会造成交互语义冲突。

**颜色纪律**（逐章，遵守约束 2 与 4）：

- 章 0：主体 ink；mark 蓝色方块 accent；锚点粒子 accent。
- 章 1：全部词 ink；七个词的锚点粒子以 1.2s/词的速度轮流点亮为 accent（「七个方向逐一被点亮」，引导扫读，同时是 scrub 静止时的时间维度生命感）。
- 章 2：主体 ink；锚点 accent。
- 章 3：主体 ink；「一」字整体 accent（最简笔划，约数十粒子，视觉上是「一笔点亮」的仪式感）；锚点 accent。
- 章 4：与章 0 mark 一致（蓝色方块 accent），归位时色彩也归位。
- 噪声态粒子一律 ink、5% 透明度，绝不用 accent（不成形时不抢戏）。

### 5.2 章 0（凝）规格

- 时序（时间驱动，收紧现状）：scatter 700ms（涡旋散开）→ gather 1800ms（弹簧聚集）→ hold 4200ms（呼吸 + 锚点轮询）→ 循环。现状为 850/2000/5200ms。
- 队形边界不变：宽 ≤ 视口 50%，居中，四周负空间。
- 语言切换时重采样文字队形（现有 sampleText 路径天然支持；英文态下「真知灼见」幕显示 `Alethic Insight`，口号幕显示 `From noise, structure.`——两句均为 index.html 现有文案）。

### 5.3 间奏带规格（章 1/2/3 共用机制）

间奏带是插入正文区块之间的 `<section class="interlude" data-interlude="directions|projects|awards" aria-hidden="true">`，自身无背景、无内容，纯负空间。

**scrub 进度定义**（shell.js 计算）：

```
p = clamp((scrollY + vh − bandTop) / (bandHeight + vh), 0, 1)
```

p=0 时带顶刚抵达视口底，p=1 时带底完全滚出视口顶。

**k（聚合度）与透明度曲线**：

| p 区间 | k | canvas 透明度 | 语义 |
|---|---|---|---|
| 0 – 0.18 | ease(p/0.18) 0→1 | 0→1（p 0–0.10 淡入） | 聚集入场 |
| 0.18 – 0.82 | 1 | 1 | 成形展示（呼吸 + 锚点轮询） |
| 0.82 – 1 | 1−ease((p−0.82)/0.18) | 1→0（p 0.90–1 淡出） | 散开退场 |

粒子完全散开与 canvas 全透明同时完成；带之后的正文 section 进入视口时场景透明度已为 0。这是「正文与粒子永不重叠」的机制保证。

**快进快退**：p 每帧实时重算，用户快速滚过时队形只走到对应进度——不强制看完；回滚时逆向播放同样成立。

**退场词汇（实测修订）**：间奏带退场保持涡旋散开，不引入 kimi 式字符雨溶解——全屏溶解词汇已被像素墙过场（transition.js）占用（换页专用），再让粒子模仿字符雨会产生两套雷同的溶解语言；涡旋散开是粒子侧独有的退场签名，且与章 0 scatter 一致。证据见 3.4 词汇 2。

**各带参数**：

| 带 | 带高 | 队形 | 采样方式 |
|---|---|---|---|
| directions | 150svh | 7 词星座，两行错排 4+3，行间距 1.2 词高 | 逐词 sampleText（词高 ≈ min(w,h)×0.14）后按网格偏移合成一个点集，点带 wordIndex |
| projects | 120svh | `FLUED` 单字，字号 min(w,h)×0.42 | 现有 sampleText 路径 |
| awards | 120svh | `一等奖`，字号 min(w,h)×0.30 | 现有 sampleText 路径；「一」字的采样点打 accent 标记（复用 mark 蓝方块识别机制的同构实现：按采样点 x 区间归属到字） |

星座排布（桌面，视口中心为原点，单位：词宽 W）：第一行 y=−0.7W，x = −1.65/−0.55/0.55/1.65W；第二行 y=0.7W，x = −1.1/0/1.1W。整体宽 ≤ 视口 70%（文字队形可以比章 0 的 50% 宽，因为星座是「阵列」而非「主体」，但高度仍受 min(w,h) 约束，四周保留负空间）。移动端改为 2 列网格（4+3 纵排），带高 100svh。

### 5.4 章 4（归）规格

- 带高 100svh，位于 `#documents` 与 `#join` 之间，`data-interlude="finale"`。
- p ∈ [0, 0.30]：mark 队形在视口中心聚集成形（尺寸 min(w,h)×0.4）。
- p ∈ [0.30, 0.90]：队形中心从视口中心 lerp 到页眉 logo 的 `getBoundingClientRect()` 中心（每帧实时取，兼容窗口变化），缩放因子从 1 → 32/队形像素尺寸（logo 为 32×32）。
- p ∈ [0.90, 1]：粒子透明度 → 0；队形与真实 logo 重叠区域在淡出完成后重合，视觉为「融入」。
- 带滚过后场景 setVisible(false) 语义扩展为「终章完成态」：回顶时重置到章 0 并恢复可见。
- 实测验证（2026-10-03）：本章手法与 kimi ch1→ch2 的镜头推移同构（3.4 词汇 1）——kimi 全程对同一粒子主体做队形级放大 + 平移、不散开重组，证实了「队形级变换（`formationScale`/`formationOffset`，不重采样）」这条技术路线的表现力上限。差异仅在终点：kimi 推向画外，本设计推向页眉 logo 完成归位。

### 5.5 reduced-motion 降级（约束 6）

- 章 0：静态 mark 成形（现有 `reduce` 分支 k=1 行为），无循环。
- 章 1/2/3：间奏带整体 `display: none`。带内信息（方向词、FLUED、一等奖）在正文中完整存在，隐藏间奏不损失任何信息——这是约束 2 与约束 6 的和解点：粒子承载的信息必须是正文信息的索引，而非唯一载体。
- 章 4：终章带隐藏，无 dock 动画。
- 指针交互、涡旋、呼吸、锚点轮询全部关闭（呼吸与轮询属动效，不在静态成形中保留）。
- 自定义指针不挂载、像素墙过场跳过（现有行为，不变）。

## 6. 一体化机制（正文与粒子交替而不重叠的规则）

1. **物理隔离**：间奏带是独立的空 section，正文 section 与之在 DOM 上互不包含；粒子 canvas 透明度只在带内滚动区间非零（5.3 曲线），正文进入视口时透明度必为 0。
2. **滚动驱动不劫持**：一切形变绑定 `scrollY`，不拦截 wheel/touch 事件，不锁定滚动；章节轨、锚点跳转、浏览器页内查找、触控板惯性全部保持原生行为。
3. **章节轨不受影响**：rail 锚点仍只指向正文 section（`#position`/`#work`/…）；间奏带无 id、不进 rail。锚点直达（如 `#work`）跳过时，间奏带按当时 p 值瞬时呈现对应状态（快进语义一致）。
4. **内容索引关系**：每个粒子队形的内容必须在其后正文区块中完整出现（方向词→方向列表、FLUED→项目表、一等奖→成果表）。反之不强制（正文内容无需全部队形化）。
5. **语言与主题**：主题切换经现有 MutationObserver 重建 sprite 与颜色；语言切换只影响章 0 的文字幕（见 5.2），间奏带内容固定（方向缩写为 Latin 事实名词、「一等奖」为正式中文名），不随 `data-lang` 重采样，避免切换时队形闪烁。
6. **子页与站外**：people / insights 页面场景不可见（现有机制）；FLUED 五页与招新平台整页跳转、完全无场景（约束 5）。
7. **透明度汇总**：canvas 最终透明度 = 页面可见性（visK，现有）× max(各带激活度)，序章带沿用现有 `1 − scrollY/(0.85vh)` 曲线作为其激活度。

### 7.2 shell.js 扩展点

- 启动时扫描 `document.querySelectorAll("[data-interlude]")` 注册带（top/height/data 类型），`resize` 时重算。
- scroll handler（现有 `updateSceneVisibility`）扩展：逐带计算 p，向 scene 派发 `setScrub`；按 6.7 汇总激活度。
- SPA 换页（swapDocument）后重新扫描带并重置场景；`data-page !== "index"` 时场景不可见（现有）。
- `INDEX_FORMATIONS` 从 shell.js 移入 `index.html` 序章 section 的 `data-formations` 属性（顺手解决 README 已记录的已知边界）。

### 7.3 index.html / styles.css 改动

- 插入 4 个间奏带 section（位置见第 4 章表格），全部 `aria-hidden="true"`、无文本内容。
- `.interlude` 样式：高度按 5.3 表格（svh 单位）、无背景、`pointer-events: none`；`@media (prefers-reduced-motion: reduce)` 下 `display: none`。
- 正文 section 无需任何改动。

### 7.4 性能预算

- 桌面：2400 粒子，DPR ≤ 2（现有上限不变）。估算：2400 次 `drawImage`/帧 ≈ 2.5ms，物理（弹簧 + 斥力 + 呼吸）≈ 1ms，合计 ≤ 4ms，60fps 预算（16.6ms）内安全。填充率：2400 × 4px² ≈ 38k px²，占 1080p 视口（DPR2 约 830 万物理像素）<2%。
- 移动端：900 粒子，尺寸降 30%，DPR cap 1.75，带高降 100svh，无指针交互（`pointer: coarse` 判定，复用 cursor.js 同款 matchMedia）。
- 硬降级：`hardwareConcurrency < 4` 或 `deviceMemory < 4` 时粒子减半、关闭呼吸与锚点轮询。
- 运行时自适应：滚动窗口内连续 30 帧帧时 >12ms，自动降档（粒子 −30%，一次到位并记录），避免低端机卡顿。
- 内存：sprite 6 张 ≤64×64 canvas 可忽略；2400 粒子对象 ≈ 300KB。

### 7.5 风险与缓解

| 风险 | 缓解 |
|---|---|
| 首页总长 +约 490svh，滚动疲劳 | 带高经 5.3 上限控制；scrub 快进不强制观看；P3 验收时若体感冗长，砍掉「器」带（FLUED 在导航 mega 菜单与项目表曝光已足够） |

| 大粒子填充率超预算 | 5.1 节尺寸分档与 7.4 节数量上限即预算；运行时自适应降档兜底 |
| 星座在窄视口不可读 | 移动端 2 列网格重排；词高与视口短边挂钩的现有自适应逻辑保留 |
| 终章 dock 与 SPA 换页竞争 | 终章带只在 index 注册；换页时场景先 reset 再 setVisible(false) |

## 8. 决策点清单（需用户拍板）

每个决策点给出选项、推荐与理由。推荐项已写入上文规格；用户改判时按本节修订。

**D1. 总体架构**
- 选项：A 全站滚动劫持章节制 / B 序章强化 + 归位 / C 间奏带穿插正文
- 推荐：C
- 理由：唯一同时满足「内容一体化」与「不劫持滚动主权」的方案；A 与章节轨/查找/触控板冲突且超出特效范围，B 没有回答一体化。

**D2. 序章是否改为滚动劫持连续 morph**
- 选项：保持时间驱动三幕循环 / 首 2–3 屏劫持滚动、mark→真知灼见→口号随滚动连续形变
- 推荐：保持时间驱动
- 理由：劫持的可用性成本集中在用户进站的前三秒，代价最高；时间驱动循环对「路过即懂」更友好。若想体验 kimi 式连续 morph，P5 以实验分支验证后再议。

**D3. 间奏带内容的语言分工**
- 选项：全部随 data-lang 双语切换 / 固定分工（方向缩写 Latin、「一等奖」中文）
- 推荐：固定分工
- 理由：LLM/CV 等缩写与「一等奖」奖项名都是事实名词，双语访客均认识；切换语言时重采样会导致队形闪烁，且中文方向全称（如「视觉语言模型」）采样字形糊、可读性差。

**D4. 终章归位目标**
- 选项：页眉 logo / 「进入招新平台」CTA 按钮 / 简单散开消失
- 推荐：页眉 logo
- 理由：「背景 → 界面元素」的闭环叙事最强，且 logo 在页眉位置稳定；CTA 在视口内位置随布局变化，dock 终点不稳。实现上粒子在到达前 12% 行程淡出，不读写真实 logo 元素。

**D5. 指针交互强度**
- 选项：维持现状斥力（90/26） / 斥力加强（140/40） / 再加按住吸引
- 推荐：斥力加强，不做按住吸引
- 理由：大粒子需要更大的交互半径才有「拨动」手感；按住吸引与自定义指针的按住填充语义冲突。

**D6. 粒子形态**
- 选项：方块（现状） / 圆形径向渐变 sprite
- 推荐：圆形 sprite
- 理由：6–8px 的方块与像素墙过场视觉撞车；圆形自带柔光晕，是「更炫酷」且不引入新色。

**D7. 星座与正文联动**
- 选项：一期做（hover 星座词 → 正文对应卡片预高亮） / P5 再做 / 不做
- 推荐：P5 再做
- 理由：间奏带 `pointer-events: none` 时 hover 需穿透检测，与 6.1 物理隔离规则有张力；先验证 scrub 叙事主干，联动作为增强。

**D8. 间奏带数量**
- 选项：3+1 全做 / 只做 曜+归 两条 / 只做 曜
- 推荐：3+1 全做，P3 验收保留砍「器」带的退路
- 理由：三章对应正文三大内容区（方向/项目/成果），缺一会在叙事弧上留缺口；但「器」带的信息增量最低，是疲劳时首选的减法。

## 9. 分期实施计划

每期独立验收，前一期是后一期依赖。

**P1 粒子引擎升级**（不改叙事结构）
- 内容：尺寸三档分级、圆形 sprite 渲染、弹簧/涡旋/呼吸物理、指针斥力加强、性能预算与运行时自适应降档落地。
- 验收：序章三幕视觉升级完成；桌面 1080p 实测稳定 60fps；噪声态 5% 透明度、单色纪律、队形 ≤50% 视口宽等约束逐项人工核对；主题切换后 sprite 重建正确。

**P2 序章（章 0）强化**
- 内容：节奏调整为 700/1800/4200ms；英文态文字幕（Alethic Insight / From noise, structure.）；reduced-motion 静态成形复核。
- 验收：序章独立可交付；语言切换重采样正确；`prefers-reduced-motion` 下静态 mark、无循环。

**P3 间奏带 ×3（曜 / 器 / 证）**
- 内容：scene.js scrub 模式与 `setScrub` API；`sampleWords` 星座合成；shell.js 带注册与 p 计算、激活度汇总；index.html 插入 3 带；样式与移动端重排。
- 验收：每条带按 5.3 曲线成形-让位；快进快退状态正确；正文区零粒子；章节轨/锚点/语言/主题/SPA 换页全部无损；移动端 2 列星座可读；此时评估滚动疲劳并决定是否砍「器」带（D8）。

**P4 终章（归）**
- 内容：dock 模式（队形级缩放/平移 + logo 坐标实时追踪 + 12% 行程淡出）；回顶/换页 reset。
- 验收：粒子飞入 logo 位置并淡出，真实 logo 全程无读写、无双重影像；回顶后序章完整重置。

**P5（可选增强包，独立评估是否启动）**
- 序章滚动劫持连续 morph 实验分支（D2）；星座 hover 联动正文（D7）；指针漩涡尾迹；移动端手感精调。
- 验收：逐项单独评审，合入前需重新过约束清单。
